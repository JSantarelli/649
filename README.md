# 649
Representación 3D de nuestras Islas Malvinas que, a través de diversos recursos visuales e interactivos, permite revisitar la gesta de Malvinas de 1982, mostrando por un lado, el impacto humano de la guerra representado por cada uno de nuestros caídos, y por otro, la reconstrucción del conflicto a partir de los eventos que se fueron sucediendo.

### Instalar dependencias
npm i

### Correr el proyecto
npm start
